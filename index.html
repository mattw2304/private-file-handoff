Private File Handoff

This is a personal-use utility for transferring files into the owner's own Google Drive account.

Purpose

The application is used only to upload, verify, and manage files in a designated private Google Drive area for the owner's own use.

Access

The application is not offered as a public service and is not intended for use by other Google users.

Google data

Google Drive access is used solely for the private file-transfer and verification functions described above. Google user data is not sold or shared with third parties.
