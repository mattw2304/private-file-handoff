Privacy Policy

Private File Handoff is a personal-use application operated by the owner of timbur.co.uk.

Google Drive access

The application uses Google Drive access only to create, transfer, list, verify, and manage files and folders created through this utility in the owner's own Google Drive account.

Data use

Google user data is used only to perform the requested private file-transfer and verification operations. It is not used for advertising, profiling, analytics, or any unrelated purpose.

Data sharing

Google user data is not sold, rented, or shared with third parties by this application.

Credentials and tokens

OAuth credentials and refresh tokens used by the file-transfer client are stored locally on the owner's computer. This website does not collect or store Google account credentials or OAuth tokens.

Retention

Files uploaded to Google Drive remain in the owner's Google Drive until the owner deletes them. This website itself stores no Google Drive file contents.

Personal-use status

This application is not offered to the public and is intended only for use by its owner.
